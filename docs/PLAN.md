# NXE Deck: build plan

Goal: ship `NXE Deck/` as a CSS Loader theme implementing Concepts B (home), C (Steam menu) and D (Quick Access) from the original design brief. The brief, its mockups and the emulator (`preview/`, which loads Steam's own stylesheets from a local client) stay out of the public repository; section numbers such as B.5 or C.6 in comments refer to the brief.

## Phases

- [x] **0. Setup.** Folder layout, `theme.json` (manifest 9), bundled Open Sans, tooling.
- [x] **1. Menus.** `mainmenu.css` (C), `quickaccess.css` (D), `controls.css` (sliders/toggles in QuickAccess and bigpicture, so Settings matches).
- [x] **2. Home.** `home.css`, plus the options ghost labels, case bands, light footer, and carousel depth (B.5, experimental).
- [x] **3. Grounding in Steam's real code.** Every selector checked against Steam's CSS and component code from the Mac client (September 2026). Rewrote toggles, sliders, the Steam menu, the QAM and home layout to match. Details in `SELECTORS.md`.
- [x] **4. Emulator rehearsal.** `preview/` renders each tab with Steam's real stylesheet and CSS Loader's translation. Expected screenshots are in `expected/`.
- [x] **5. First hardware pass (v0.1).** Home skin applied on a Deck. Findings: the Deck renders at 854×534 CSS px scaled 1.5× (the theme was 1.5× too big), CSS Loader doubles backslashes (broke the case-band text), and white L1/R1 glyphs hid the tab shortcut.
- [x] **5b. v0.2.** Rescaled everything to the design's proportions, added an NXE green background (CSS, original) with Silver studio and Custom image alternatives, turned Carousel depth on by default, made L1/R1 glyphs visible, and emulated both findings in the tools.
- [x] **5c. v0.3: NXE scrolling.** The focused game is always left-most and earlier games slide off (`options/scroll.css`, generated by `tools/gen_scroll.py` from Steam's scroll maths). Verified by measurement in the emulator for all three carousel layouts, first game to last.
- [x] **5d. v0.4.** Friends/Recommended tabs readable on the light panel (they were white-on-silver, so switching looked like nothing happened); Steam menu accent bar follows the selection; accent presets with the sky following the accent.
- [x] **5e. v0.5.** Focused capsule in front of the ones behind it (z-index front-to-back; Steam enlarges it with translateZ). Home tabs: pages are matched to the selected tab via Steam's ARIA labels, so the content switches even when Steam's page transition never finishes (it kept the old page on top on a Deck).
- [x] **5f. v0.5.1.** What's New lower sections (Recently completed, store carousel) readable on the light panel; dark ink as the default text on the panel. Tab pages: still not switching on the Deck although every emulated case works, so Debug outlines now prints the live tab DOM for a screenshot diagnosis.
- [x] **5g. v0.5.2.** "Special Offers" (marketingmessages) heading and a catch-all for every section <h2> on the light panel. First Deck diagnostic screenshot: the selected-tab detection works on the Deck ("SELECTED TAB: WhatsNew"); page labels were hidden under the tab row, now fixed above the footer.
- [x] **5h. Tabs: not a theme bug.** With all CSS themes off the home tabs still don't switch on this Deck. Steam stores the home tab in router history state (`HomeActiveTab_HistoryValue`, set with `history.replace` on the same URL) and the view only redraws when the router passes that on; here it doesn't, so the content updates only on remount. Likely a Decky plugin patching the home route or a Steam client bug; see the reply for the test sequence. The ARIA page-matching rules stay as a harmless safeguard.
- [x] **5i. v0.6: Library.** The Home look carried over to the Library (not in the handoff): clean accent sky at dusk (no bokeh since v0.6.1), graphite tab strip with silver selected tab, capsule rims and outside focus rings, case bands, sticky section headers, Collections tiles, light footer. "Library skin" option. Emulated in `preview/library.html` (grid, Collections tab, sticky headers, all background options).
- [x] **5j. v0.6.1–v0.6.2.** Library background without bokeh (user's call). Quick Access buttons and focused rows themed (they were stock in the user's Decky screenshot); markup read live from the Deck over CEF through the SSH tunnel; `preview/qam.html?tab=decky`.
- [x] **5k. v0.7: Game page.** A game's details page gets the Library look (user's Deck screenshot showed it stock): dusk sky in place of the blurred hero copy, accent line under the hero, glossy Play button keeping Steam's state colours, dark keys, Library tabs, dark glossy cards, accent achievement bars, light footer. "Game page skin" option. `preview/details.html` is a sanitized snapshot of the live page taken over CEF.
- [x] **5l. v0.7.1.** From the user's screenshots: the gear menu (Steam's gamepad context menu, now styled everywhere via `dialogs.css`: dark panel, silver focused row with accent tab, dividers, C.6 scrim), Steam's generic focus ring (white rim + accent ring), Community tab cards, and a game's controller settings page. `tools/deckdom.mjs` reads and snapshots the live UI over the CEF tunnel; `preview/controller.html` is a sanitized snapshot.
- [x] **5m. v0.7.2.** Gear menu boxed (the Deck's gamepad menu has no panel element; the box goes on each level's row list, Steam's 15/40px scroll margins removed). Opaque top bar made transparent; the controller pages paint their sky under it. View Layout (controllerconfiguratorsummary) themed.
- [x] **5n. v0.7.3: Steam menu.** The menu is its own 240×534 window (read live): the 268px panel overflowed it, was clipped on the right, and Steam's focus scrolling shifted the whole menu 8px left as the selection moved, taking the accent bar (in the gutter) out of view. Panel back to 240px, accent tab inside the silver bar, gamercard band removed (user's call).
- [x] **5o. v0.8–v0.8.1: Other pages.** Downloads, Settings (and every paged settings screen, e.g. game Properties), Media and Friends & Chat, all read live from the Deck (a route watcher captured each as the user opened it; Settings and Friends structure-only, no text). "Other pages" option (`pages.css`). Friends & Chat turned out to be the Quick Access window in a wide mode, so its rules live in `quickaccess.css`. Media's classes only exist under CSS Loader's generated names (`_mP9RJOCZ_…`, `_wEPhzApt_…`).
- [x] **5p. v0.9: Case bands by source.** The user's idea: STEAM / HEROIC / RETRO / APP bands in matching colours. A capsule only exposes its art address; non-Steam shortcuts and SteamGridDB-art Steam games share `/customimages/`, so `tools/gen_sources.py` reads the Deck's `shortcuts.vdf` over SSH, classifies each shortcut by its launch command, and writes `options/sources.css` (numeric IDs only). `deploy.sh` runs it each time.
- [x] **5q. v0.9.1: In-game.** The running game's panel (Steam button → the game; module `mainmenuapprunning`, generated names `_xfZ18oWU_…`), read live while a game ran: sky behind it, rows on the dark panel with the silver bar and accent tab, light preview side. The folded 44px Steam menu kept its labels and padding, overflowed and scrolled sideways; now centred icons only. Background options also reach the MainMenu and QuickAccess windows.
- [x] **5r. v0.9.2: Achievements.** The list's tabbed page was window-tall inside a half-height area, so it scrolled within the lower half and focus could move below the visible part. The tabbed page now fills its area, and a scroll-driven animation (`scroll-timeline` + `timeline-scope`, supported by the Deck's CEF) folds the summary away over the first 160px of list scroll. `dialogs.css` now also loads in the MainMenu window (in-game panel).
- [x] **5s. v0.9.3: Carousel motion in one move.** Steam scrolls the home carousel first (120ms, "sine") and only moves the focus when the scroll completes, so focus-keyed depth always ran after the slide (measured in the emulator: scroll 0–116ms, then depth 116–466ms). Depth, z-order and the left fade now follow each column's position via scroll-driven view timelines (`view-timeline: --nxe-col`), and NXE scrolling's start-of-list offset uses `margin-left` (seen by view timelines; transforms aren't). Everything now settles inside Steam's scroll. The emulator scrolls first and focuses after, like Steam.
- [x] **5t. v0.9.4.** "Go to Library" pivots at the games' centre height (its box is 201px vs the games' 253px with the label strip, so it shrank around a point 26px higher and sat above the depth line). Steam's generic confirmation dialog (exit game, uninstall, …; `gamepaddialog_ModalPosition > GamepadDialogContent`) themed in `dialogs.css`: dark panel, accent-band title, keys.
- [ ] **5u. Second hardware pass (next).** `TESTING.md` again, focusing on the Library, the Steam menu and Quick Access (not yet seen on hardware), depth scrolling, and the Floor line.
- [ ] **6. Open items.** C.6 scrim (find Steam's backdrop in the live DOM). Optional case-band artwork (specs in `TESTING.md`).
- [ ] **7. v1.0.0 release.** Repo prepared for GitHub: README, MIT licence, changelog, dev notes in `docs/`; `options/sources.css` ships neutral and `deploy.sh` writes the personal copy onto the Deck only. ## Theme options

| Option | Default | What it does |
|---|---|---|
| Accent | NXE Green | Presets (NXE Green, Blue, Orange, Purple, Red, Pink, Teal, Silver) or Custom, which shows a colour picker. The sky, bands, badges and focus rings all follow it |
| Background | NXE green | NXE green (CSS lime sky + silver floor), Silver studio (the spec's original), or Custom image. The Library gets a darker variant of each (dusk sky, graphite, dimmed wallpaper) |
| Wallpaper | bundled sample | Image picker, used when Background is "Custom image"; picks any image in `~/homebrew/themes/` |
| Floor line | 57% | Height of the horizon; set it just under the capsules |
| Library skin | on | The Home look on the Library: sky, tab strip, capsules, section headers, Collections |
| Other pages | on | Downloads, Settings (and game Properties) and Media: sky, dark cards, keys, accent focus |
| Game page skin | on | The same look on a game's page (sky under the hero, glossy Play button, keys, tabs, cards, Community cards), its controller settings and View Layout |
| NXE scrolling | on | The focused game is always left-most; earlier games slide off to the left |
| Carousel depth | on | Capsules after the focused one shrink and rise (the NXE blade) |
| Ghost channels | on | "Store / Library" labels above the pill |
| Case bands | By source | By source: STEAM (Steam blue), HEROIC (violet), RETRO (grey), APP (graphite) per capsule; Steam Deck: the accent band reading STEAM DECK; Off. Home and Library |
| Light footer | on | Light legend bar on Home, the Library, game pages, controller settings, Downloads, Settings and Media |
| Debug outlines | off | Outlines every targeted element, for hardware testing |

## Tools

| Command | Purpose |
|---|---|
| `python3 tools/check_theme.py` | Static checks: manifest, class names in CSS Loader's table and in the local Steam client, known-bad names |
| `python3 tools/steamcss.py <module_Class>` | Print Steam's own rules for a class (`--module`, `--js` too) |
| `python3 tools/gen_depth.py` | Regenerate `options/depth.css` |
| `python3 tools/gen_scroll.py` | Regenerate `options/scroll.css` |
| `node tools/cdp.mjs eval <url> '<js>'` | Evaluate JS in an emulator page (after `--keys`), print the result |
| `node tools/cdp.mjs shoot <url> <png>` | Emulator screenshot at the Deck's 854×534 @1.5× = 1280×800 (`--keys ArrowRight,…` for D-pad) |
| `node tools/cdp.mjs probe <url>` | Run the selector probe against an emulator page |
| `node tools/cdp.mjs deck <deck-ip>` | On hardware: screenshots and probe report per tab |
| `DECK=deck@<ip> tools/deploy.sh` | Copy the theme to the Deck over SSH |
| `node tools/deckdom.mjs targets\|eval\|dump\|snapshot …` | Read-only look at the live Steam UI over the CEF tunnel (`ssh -f -N -L 127.0.0.1:8081:localhost:8080 deck@<ip>`); `snapshot` saves sanitized markup for an emulator page |
| `tools/package.sh` | Build `dist/NXE-Deck-<version>.zip` |
| `DECK=deck@<ip> python3 tools/gen_sources.py --out FILE` | Case bands "By source": write a Deck's shortcut categories to FILE (`deploy.sh` does this and copies the result onto the Deck; the theme itself ships the neutral `--empty` output) |

The emulator runs on the `nxe-preview` launch config (`python3 -m http.server 8765 --directory preview`). Open `/home.html` (add `?layout=running` or `?layout=plain` for the other carousel layouts), `/library.html` (`?tab=Collections`, `?scrolled=1`), `/details.html` (a game page, `?scrolled=1`, `?menu=1`, `?tab=community`), `/controller.html` (`?view=1` for View Layout), `/steam-menu.html` or `/qam.html` (`?tab=decky` for Decky's plugin list); `/bg.html` renders the NXE green alone (source of `images/nxe-green.jpg`). `preview/steamui` is a symlink into the Steam client, and nothing from Valve is copied into the project.
